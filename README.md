# What Makes a Recipe Highly Rated?

### Exploring the Relationship Between Recipe Characteristics and User Ratings

**By Joe Liu**
**DSC 80 | UC San Diego**

This project explores how recipe characteristics, such as preparation time, number of steps, and nutritional content, relate to user ratings. The analysis uses the [Recipes and Ratings dataset from Food.com](https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions), available on Kaggle.
